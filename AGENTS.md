## 1. Project Intent & Overview

**ext.to-rss** is a high-performance proxy service built with **FastAPI**, **curl_cffi**, **Playwright**, and **BeautifulSoup4**. It scrapes the `ext.to` / `extto.com` torrent index aggregator and translates search results into:
1. **Torznab API (`/api`)**: Compatible with Prowlarr, Sonarr, Radarr, and Lidarr.
2. **RSS 2.0 Feed (`/rss` & `/feed.xml`)**: Compatible with standard RSS feed aggregators.

### Core Challenges Solved
- **Cloudflare & Anti-Bot Protection**: Bypasses Turnstile/Cloudflare protection using `curl_cffi` Chrome TLS fingerprint impersonation across mirror domains (`extto.com`, `ext.to`, `ext2.to`) with Playwright stealth fallback.
- **Dynamic Magnet Link Security**: Magnet URIs on `ext.to` are dynamically retrieved via AJAX POST requests signed with SHA256 HMAC signatures (`hashlib.sha256(f"{torrent_id}|{timestamp}|{page_token}".encode("utf-8")).hexdigest()`).
- **Torznab Compliance**: Formats torrent items with `<link>`, `<enclosure>`, and `<torznab:attr>` tags required by Prowlarr.

## 3. Critical Rules for AI Agents

When modifying this codebase, AI agents MUST strictly adhere to the following rules:

### A. Code Standards & Data Integrity
1. **Do Not Guess Schemas or Selectors**: Inspect HTML structures directly or run target test scripts before changing BeautifulSoup selectors in `app/scraper/parser.py`.
2. **Torznab XML Spec Compliance**: Every `<item>` generated by `app/torznab/xml_builder.py` MUST contain valid `<link>` and `<enclosure>` elements. Missing these causes C# `NullReferenceException` crashes in Prowlarr.
3. **Async Database Operations**: Always use `aiosqlite` in `app/cache/db.py`. Do not introduce blocking synchronous `sqlite3` calls on main event loops.
4. **Preserve TLS Impersonation Fallback Order**: Primary fetch MUST attempt fast `curl_cffi` TLS impersonation first (`impersonate="chrome120"`). Playwright Chromium stealth should only launch if CloudflareTurnstile challenges are detected.

### B. Verification & Testing Directive
- **Never declare victory without running test commands**. Before marking any task complete, agents MUST run the full test suite and confirm 100% pass:
  ```powershell
  .venv\Scripts\python -m pytest tests/
  ```

## 4. Commands Cheatsheet for AI Agents

### Environment Setup
```powershell
# Create and activate virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install dependencies and Playwright Chromium binaries
pip install -r requirements.txt
playwright install chromium
```

### Running Tests
```powershell
# Run full pytest suite
.venv\Scripts\python -m pytest tests/
```

### Running Local Development Server
```powershell
# Start FastAPI ASGI server on host 0.0.0.0 port 8000
.venv\Scripts\uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Running with Docker
```powershell
# Build and launch with Docker Compose
docker-compose up -d --build
```
